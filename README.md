## 🚀 Getting Started

### Prerequisites
- **Node.js** 18+ 
- **Bun** (recommended) or npm/yarn
- **Git**

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/deekshith-b48/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   bun install
   # or
   npm install
   ```

3. **Start development server**
   ```bash
   bun run dev
   # or
   npm run dev
   ```

4. **Build for production**
   ```bash
   bun run build
   # or
   npm run build
   ```

5. **Preview production build**
   ```bash
   bun run preview
   # or
   npm run preview
   ```
